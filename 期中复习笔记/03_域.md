# 主题3：域

## 1. 域的定义

**域** 是一个标量集合 $\mathbb{F}$，对定义在其上的加法 $+$ 和乘法 $\times$ 满足：

### 加法性质（$\mathbb{F}$ 是加法群）
| 性质 | 描述 |
|-----|------|
| 封闭性 | $a + b \in \mathbb{F}$ |
| 交换律 | $a + b = b + a$ |
| 结合律 | $(a + b) + c = a + (b + c)$ |
| 单位元 | 存在 $0$ 使得 $a + 0 = a$ |
| 逆元 | 存在 $-a$ 使得 $a + (-a) = 0$ |

### 乘法性质（$\mathbb{F}^* = \mathbb{F}\setminus\{0\}$ 是乘法群）
| 性质 | 描述 |
|-----|------|
| 封闭性 | $a \cdot b \in \mathbb{F}$ |
| 交换律 | $a \cdot b = b \cdot a$ |
| 结合律 | $(a \cdot b) \cdot c = a \cdot (b \cdot c)$ |
| 单位元 | 存在 $1$ 使得 $a \cdot 1 = a$ |
| 逆元 | 对 $a \neq 0$，存在 $a^{-1}$ 使得 $a \cdot a^{-1} = 1$ |

### 分配律
$$a \cdot (b + c) = a \cdot b + a \cdot c$$

**典型的域**：$\mathbb{Q}$（有理数域）、$\mathbb{R}$（实数域）、$\mathbb{C}$（复数域）

---

## 2. 数域

> **定义**：设 $K$ 是 $\mathbb{C}$ 的子集，且至少有两个不同元素。若 $K$ 对加、减、乘、除（除数不为零）封闭，则称 $K$ 是一个数域。

> **定理**：任一数域 $K$ 必定包含有理数域 $\mathbb{Q}$。

**证明要点**：
1. 由 $K$ 至少有两个元素，且对减法封闭，知 $0, 1 \in K$
2. 由对加法封闭，知所有正整数 $\in K$
3. 由对减法封闭，知所有整数 $\in K$
4. 由对除法封闭，知所有有理数 $\in K$

---

## 3. 域的特征

**定义**：域 $\mathbb{F}$ 的特征 $p$ 是最小的正整数，使得
$$\underbrace{1 + 1 + \cdots + 1}_{p \text{ 个}} = 0$$

若这样的正整数不存在，则称该域的特征为零。

> **定理**：域的特征只能是 $0$ 或素数。

**证明**：反证法。假设特征 $p = mn$ 是合数（$m, n > 1$），则
$$0 = \underbrace{1 + \cdots + 1}_{mn \text{ 个}} = (\underbrace{1 + \cdots + 1}_{m \text{ 个}})(\underbrace{1 + \cdots + 1}_{n \text{ 个}})$$

由于域中无零因子，必有一项为零，与 $p$ 是最小正整数矛盾。

**数域的特征一定为零**。

## 4. 域的同态与同构

### 同态
映射 $\phi: \mathbb{F}_1 \to \mathbb{F}_2$ 称为同态，若满足：
1. **保持运算**：$\phi(a + b) = \phi(a) + \phi(b)$，$\phi(ab) = \phi(a)\phi(b)$
2. **保持单位元**：$\phi(0_{\mathbb{F}_1}) = 0_{\mathbb{F}_2}$，$\phi(1_{\mathbb{F}_1}) = 1_{\mathbb{F}_2}$

### 同构
同态 $\phi$ 若还是双射，则称为同构，记作 $\mathbb{F}_1 \cong \mathbb{F}_2$。

> 同构的两个域在代数结构上完全相同。

**例子**：
- $\mathbb{C} \cong \left\{ \begin{pmatrix} a & -b \\ b & a \end{pmatrix} : a, b \in \mathbb{R} \right\}$
- $\mathbb{Q}(\sqrt{2}) \cong \mathbb{Q}[x]/(x^2 - 2)$
