# 主题10：谱分解

## 1. 正规矩阵

### 1.1 定义

设 $A \in \mathbb{C}^{n \times n}$。若 $A^H A = A A^H$，则称 $A$ 为**正规矩阵**（normal matrix）。

**重要特例**：
- Hermite 矩阵：$A^H = A$
- 反 Hermite 矩阵：$A^H = -A$
- 酉矩阵：$A^H A = I$

### 1.2 正规矩阵的谱分解

> **定理**：$A$ 正规 $\Leftrightarrow$ $A$ 可酉对角化，即存在酉矩阵 $U$ 使得
> $$A = U \Lambda U^H = \sum_{i=1}^n \lambda_i u_i u_i^H$$
> 其中 $\Lambda = \mathrm{diag}(\lambda_1, \ldots, \lambda_n)$，$u_i$ 是 $U$ 的第 $i$ 列。

**证明**：

**充分性**：若 $A = U \Lambda U^H$，则 $A^H = U \Lambda^H U^H$，于是
$$A^H A = U \Lambda^H \Lambda U^H = U \Lambda \Lambda^H U^H = A A^H$$
故 $A$ 正规。

**必要性**：设 $A$ 正规。由 Schur 分解，存在酉矩阵 $U$ 使得 $U^H A U = T$ 为上三角阵。

由于 $A$ 正规，
$$T^H T = U^H A^H A U = U^H A A^H U = T T^H$$

设 $T = (t_{ij})$，比较 $(T^H T)_{ii}$ 和 $(T T^H)_{ii}$：
$$(T^H T)_{ii} = \sum_{k=1}^n \bar{t}_{ki} t_{ki} = \sum_{k=1}^n |t_{ki}|^2$$
$$(T T^H)_{ii} = \sum_{k=1}^n t_{ik} \bar{t}_{ik} = \sum_{k=1}^n |t_{ik}|^2$$

由 $T^H T = T T^H$，得 $\sum_{k=1}^n |t_{ki}|^2 = \sum_{k=1}^n |t_{ik}|^2$。

由于 $T$ 是上三角阵，$t_{ki} = 0$ 当 $k > i$，$t_{ik} = 0$ 当 $k < i$。

代入得 $|t_{ii}|^2 = |t_{ii}|^2 + \sum_{k<i} |t_{ki}|^2 + \sum_{k>i} |t_{ik}|^2$。

这要求 $\sum_{k<i} |t_{ki}|^2 = 0$ 和 $\sum_{k>i} |t_{ik}|^2 = 0$，即 $t_{ki} = 0$（$k < i$）和 $t_{ik} = 0$（$k > i$）。

因此 $T$ 是对角阵，$A$ 可酉对角化。 $\square$

## 2. Hermite 矩阵的谱分解

### 2.1 基本性质

Hermite 矩阵是正规矩阵的特例，具有以下性质：
- 特征值均为实数
- 不同特征值对应的特征向量正交
- 存在由特征向量组成的标准正交基

### 2.2 谱分解形式

设 $A$ 是 Hermite 矩阵，特征值为 $\lambda_1, \ldots, \lambda_n$（可能有重根），对应的标准正交特征向量为 $u_1, \ldots, u_n$，则
$$A = \sum_{i=1}^n \lambda_i u_i u_i^H = U \Lambda U^H$$

### 2.3 谱投影

定义谱投影算子：
$$P_i = u_i u_i^H$$
则 $P_i$ 是到特征空间 $\mathcal{E}_{\lambda_i}$ 的正交投影，满足 $P_i^2 = P_i$，$P_i^H = P_i$，$P_i P_j = 0$（$i \neq j$）。

## 3. 惯性定理与惯性指数

### 3.1 惯性指数

Hermite 矩阵 $A$ 的**惯性指数**定义为三元组 $(i_+, i_-, i_0)$：
- $i_+$：正特征值个数（正惯性指数）
- $i_-$：负特征值个数（负惯性指数）
- $i_0$：零特征值个数

### 3.2 Sylvester 惯性定理

> **定理**：Hermite 阵 $A, B$ 共轭相合 $\Leftrightarrow$ 它们具有相同的惯性指数。

**推论**：共轭相合变换不改变 Hermite 矩阵特征值的符号。

### 3.3 惯性矩阵

Hermite 阵 $A$ 共轭相合于其惯性矩阵：
$$A \simeq \begin{pmatrix} I_{i_+} & 0 & 0 \\ 0 & -I_{i_-} & 0 \\ 0 & 0 & 0_{i_0} \end{pmatrix}$$

## 4. Rayleigh-Ritz 定理

### 4.1 极值刻画

> **定理**（Rayleigh-Ritz）：设 $A$ 是 Hermite 矩阵，特征值按非减次序排列 $\lambda_1 \leq \cdots \leq \lambda_n$，则
> $$\lambda_1 = \min_{\|x\|=1} x^H A x, \quad \lambda_n = \max_{\|x\|=1} x^H A x$$

**证明**：
设 $A = U \Lambda U^H$ 是谱分解，其中 $\Lambda = \mathrm{diag}(\lambda_1, \ldots, \lambda_n)$。

对于任意单位向量 $x$，令 $y = U^H x$，则 $\|y\| = 1$。

$$x^H A x = x^H U \Lambda U^H x = y^H \Lambda y = \sum_{i=1}^n \lambda_i |y_i|^2$$

由于 $\sum_{i=1}^n |y_i|^2 = 1$，这是 $\lambda_i$ 的凸组合，故
$$\lambda_1 = \min_i \lambda_i \leq \sum_{i=1}^n \lambda_i |y_i|^2 \leq \max_i \lambda_i = \lambda_n$$

当 $x = u_1$（对应 $\lambda_1$ 的特征向量）时，$x^H A x = \lambda_1$ 取到最小值。
当 $x = u_n$（对应 $\lambda_n$ 的特征向量）时，$x^H A x = \lambda_n$ 取到最大值。 $\square$

### 4.2 Courant-Fischer 定理（min-max 定理）

> **定理**：对于 $k = 1, \ldots, n$：
> $$\lambda_k = \min_{\dim S = n-k+1} \max_{x \in S, \|x\|=1} x^H A x = \max_{\dim S = k} \min_{x \in S, \|x\|=1} x^H A x$$

## 5. Weyl 不等式

### 5.1 特征值扰动

设 $A, B, C$ 是 Hermite 矩阵，$A = B + C$。设特征值按非减次序排列，则：

> **定理**（Weyl 不等式）：对于任意 $i, j$：
> $$\lambda_i(A) \geq \lambda_i(B) + \lambda_1(C)$$
> $$\lambda_i(A) \leq \lambda_i(B) + \lambda_n(C)$$

**常用形式**：
$$|\lambda_i(A) - \lambda_i(B)| \leq \|A - B\|_2$$

### 5.2 Hoffman-Wielandt 不等式

> **定理**：设 $A, B$ 是 Hermite 矩阵，特征值按非减次序排列，则
> $$\sqrt{\sum_{i=1}^n (\lambda_i(A) - \lambda_i(B))^2} \leq \|A - B\|_F$$

## 6. Cauchy 交错定理

### 6.1 主子阵的特征值

> **定理**（Cauchy 交错）：设 $A \in \mathbb{C}^{n \times n}$ 是 Hermite 矩阵，$B$ 是 $A$ 的 $n-1$ 阶主子阵。设 $A, B$ 的特征值按非减次序排列分别为 $\lambda_1 \leq \cdots \leq \lambda_n$ 和 $\mu_1 \leq \cdots \leq \mu_{n-1}$，则
> $$\lambda_1 \leq \mu_1 \leq \lambda_2 \leq \mu_2 \leq \cdots \leq \mu_{n-1} \leq \lambda_n$$

### 6.2 几何意义

Hermite 矩阵加边扩充或删边约简，新旧特征值必定交错。

---

## 7. 可交换 Hermite 矩阵的同时对角化

> **定理**：设 $\mathcal{F}$ 是 Hermite 矩阵族。$\mathcal{F}$ 中矩阵两两可交换 $\Leftrightarrow$ 它们可以同时酉对角化。

即存在酉矩阵 $U$，使得对于任意 $A \in \mathcal{F}$，$U^H A U$ 都是对角阵。
