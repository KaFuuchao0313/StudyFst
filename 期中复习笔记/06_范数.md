# 主题6：范数

## 1. 范数的定义

> **定义**：设 $V$ 是域 $\mathbb{F}$ 上的线性空间，函数 $\|\cdot\|: V \to \mathbb{R}$ 称为一个**范数**，如果它满足下列四条公理：
>
> 1. **非负性**：$\|x\| \geq 0$
> 2. **正定性**：$\|x\| = 0$ 当且仅当 $x = 0$
> 3. **齐次性**：$\|\alpha x\| = |\alpha| \|x\|,\ \forall \alpha \in \mathbb{F}$
> 4. **次可加性（三角不等式）**：$\|x + y\| \leq \|x\| + \|y\|$

**半范数**：若函数 $\|\cdot\|$ 不满足正定性，但满足其他三个性质，则称其为**半范数**（semi-norm）。非零向量的半范数可能为零。

**赋范空间**：线性空间 $V$ 与给定的范数 $\|\cdot\|$ 合在一起，称为一个**赋范空间**（normed linear space）。

**完备三角不等式**：$\|x - y\| \geq \big|\|x\| - \|y\|\big|$，当且仅当 $y$ 是 $x$ 的非正实数倍时取等。

## 2. 向量范数

### 2.1 $p$-范数

设 $x \in \mathbb{C}^n$，$p \geq 1$，则 **$p$-范数**定义为：
$$\|x\|_p = \left(\sum_{i=1}^{n}|x_i|^p\right)^{\frac{1}{p}}$$

**三种常用范数**：
| 范数 | 定义 | 别名 |
|------|------|------|
| $\|x\|_1$ | $\sum_{i=1}^{n}\|x_i\|$ | 和范数、Manhattan范数 |
| $\|x\|_2$ | $\sqrt{\sum_{i=1}^{n}\|x_i\|^2}$ | Euclid范数 |
| $\|x\|_\infty$ | $\max_{1 \leq i \leq n} \|x_i\|$ | 最大值范数 |

**重要性质**：
- $\|\cdot\|_2$ 是**酉不变的**（unitarily invariant）：对任意酉矩阵 $U$，有 $\|Ux\|_2 = \|x\|_2$
- $\|\cdot\|_2$ 的正倍数是 $\mathbb{C}^n$ 上仅有的酉不变范数

**$k$-范数**：对于 $1 \leq k \leq n$，向量 $x$ 的 $k$-范数是 $x$ 的前 $k$ 大分量模长的和：
$$\|x\|_{[k]} = \sum_{i=1}^{k} |x_{(i)}|$$
其中 $|x_{(1)}| \geq |x_{(2)}| \geq \cdots \geq |x_{(n)}|$ 是 $x$ 各分量模长的降序排列。

### 2.2 范数的等价性

> **定理**：有限维实或复向量空间中的所有范数都是等价的。即对任意两种范数 $f_1, f_2$，存在常数 $m, M > 0$，使得
> $$mf_1(x) \leq f_2(x) \leq Mf_1(x),\ \forall x$$

**证明**：
只需证明任意范数 $f$ 与 $\|\cdot\|_\infty$ 等价。

设 $\{e_1, \ldots, e_n\}$ 是标准基。对于任意 $x = \sum_{i=1}^n x_i e_i$，
$$f(x) = f\left(\sum_{i=1}^n x_i e_i\right) \leq \sum_{i=1}^n |x_i| f(e_i) \leq \|x\|_\infty \sum_{i=1}^n f(e_i) = M \|x\|_\infty$$

其中 $M = \sum_{i=1}^n f(e_i)$。

另一方面，定义单位球面 $S = \{x : \|x\|_\infty = 1\}$，它是紧集。

$f$ 作为范数是连续函数（由三角不等式可得 Lipschitz 连续）。

$f$ 在紧集 $S$ 上取得最小值 $m > 0$（因为 $f(x) = 0 \Leftrightarrow x = 0$，而 $S$ 不含零向量）。

对于任意非零 $x$，$\frac{x}{\|x\|_\infty} \in S$，故
$$f\left(\frac{x}{\|x\|_\infty}\right) \geq m$$

即 $f(x) \geq m \|x\|_\infty$。 $\square$

**推论**：
- 向量序列依范数收敛 $\Leftrightarrow$ 依坐标收敛
- 有限维赋范空间上的范数都是一致连续函数

### 2.3 对偶范数

设 $\|\cdot\|$ 为 $\mathbb{C}^n$ 上的范数，其**对偶范数**定义为：
$$\|x\|_* = \max_{\|y\| \leq 1} |\langle x, y \rangle| = \max_{\|y\| = 1} |\langle x, y \rangle|$$

**重要性质**：
- 对偶范数的对偶等于原范数：$\|x\|_{**} = \|x\|$
- $\|\cdot\|_p$ 的对偶范数是 $\|\cdot\|_q$，其中 $\frac{1}{p} + \frac{1}{q} = 1$
- $\|\cdot\|_2$ 是仅有的自对偶范数

## 3. Hölder 不等式与 Minkowski 不等式

### 3.1 Hölder 不等式

> **定理**（Hölder 不等式）：若 $p, q$ 为共轭指标（$\frac{1}{p} + \frac{1}{q} = 1$，$p, q > 1$），则对于任意 $x, y \in \mathbb{C}^n$：
> $$|\langle x, y \rangle| \leq \|x\|_p \|y\|_q$$
> 当且仅当存在 $c \geq 0$ 使得 $|y| = c|x|^{\frac{p}{q}}$ 且 $x, y$ 线性相关时取等。

**证明**：

利用 Young 不等式：对于 $a, b \geq 0$，有 $ab \leq \frac{a^p}{p} + \frac{b^q}{q}$。

设 $x, y$ 非零（否则显然成立）。令
$$\tilde{x} = \frac{x}{\|x\|_p}, \quad \tilde{y} = \frac{y}{\|y\|_q}$$

由 Young 不等式：
$$|\tilde{x}_i \tilde{y}_i| \leq \frac{|\tilde{x}_i|^p}{p} + \frac{|\tilde{y}_i|^q}{q}$$

两边求和：
$$\sum_{i=1}^n |\tilde{x}_i \tilde{y}_i| \leq \frac{1}{p}\sum_{i=1}^n |\tilde{x}_i|^p + \frac{1}{q}\sum_{i=1}^n |\tilde{y}_i|^q = \frac{1}{p} + \frac{1}{q} = 1$$

因此 $|\langle x, y \rangle| \leq \|x\|_p \|y\|_q$。 $\square$

**特例**：当 $p = q = 2$ 时，Hölder 不等式即为 **Cauchy-Schwarz 不等式**。

### 3.2 Minkowski 不等式

> **定理**（Minkowski 不等式）：对于 $p \geq 1$ 和任意 $x, y \in \mathbb{C}^n$：
> $$\|x + y\|_p \leq \|x\|_p + \|y\|_p$$

**证明**：

当 $p = 1$ 时显然成立。

当 $p > 1$ 时，设 $q$ 为 $p$ 的共轭指标。注意到：
$$\|x + y\|_p^p = \sum_{i=1}^n |x_i + y_i|^p = \sum_{i=1}^n |x_i + y_i| \cdot |x_i + y_i|^{p-1}$$

利用 $|x_i + y_i| \leq |x_i| + |y_i|$：
$$\|x + y\|_p^p \leq \sum_{i=1}^n |x_i| \cdot |x_i + y_i|^{p-1} + \sum_{i=1}^n |y_i| \cdot |x_i + y_i|^{p-1}$$

对每一项应用 Hölder 不等式：
$$\sum_{i=1}^n |x_i| \cdot |x_i + y_i|^{p-1} \leq \|x\|_p \cdot \left(\sum_{i=1}^n |x_i + y_i|^{(p-1)q}\right)^{\frac{1}{q}} = \|x\|_p \cdot \|x + y\|_p^{p-1}$$

同理处理第二项，得到：
$$\|x + y\|_p^p \leq (\|x\|_p + \|y\|_p) \cdot \|x + y\|_p^{p-1}$$

两边除以 $\|x + y\|_p^{p-1}$（设 $x + y \neq 0$），即得结论。 $\square$

## 4. 矩阵范数

### 4.1 矩阵范数的定义

函数 $\|\cdot\|: \mathbb{C}^{m \times n} \to \mathbb{R}$ 称为一个**矩阵范数**，如果它满足：
1. 非负性：$\|A\| \geq 0$
2. 正定性：$\|A\| = 0$ 当且仅当 $A = O$
3. 齐次性：$\|\alpha A\| = |\alpha| \|A\|$
4. 次可加性：$\|A + B\| \leq \|A\| + \|B\|$

### 4.2 相容范数

矩阵范数 $\|\cdot\|$ 称为**相容的**（compatible），如果满足：
$$\|AB\| \leq \|A\| \|B\|$$

**重要性质**：对于任何相容范数，有 $\|I\| \geq 1$。满足 $\|I\| = 1$ 的相容范数称为**单位的**（unital）。

### 4.3 Frobenius 范数

$$\|A\|_F = \sqrt{\sum_{i=1}^m \sum_{j=1}^n |a_{ij}|^2} = \sqrt{\operatorname{tr}(A^H A)}$$

**性质**：
1. **计算公式**：$\|A\|_F = \sqrt{\langle A, A \rangle_F}$，其中 Frobenius 内积 $\langle A, B \rangle_F = \operatorname{tr}(A^H B)$
2. **酉不变性**：对任意酉矩阵 $U, V$，有 $\|UAV\|_F = \|A\|_F$
3. **范数不等式**：$\|A\|_2 \leq \|A\|_F \leq \sqrt{\min(m,n)} \|A\|_2$

## 5. 诱导范数与谱范数

### 5.1 诱导范数

设 $\|\cdot\|$ 为向量范数，相应的**诱导范数**（或算子范数）定义为：
$$\|A\| = \max_{\|x\| = 1} \|Ax\| = \max_{x \neq 0} \frac{\|Ax\|}{\|x\|}$$

**性质**：
- 诱导范数一定是相容范数且是单位的
- 向量范数与其诱导范数相容：$\|Ax\| \leq \|A\| \|x\|$

**证明（诱导范数是相容范数）**：

首先验证范数四条公理：

1. **非负性**：$\|A\| \geq 0$ 显然。

2. **正定性**：若 $\|A\| = 0$，则 $\|Ax\| = 0$ 对所有 $\|x\| = 1$ 成立，故 $Ax = 0$ 对所有 $x$ 成立，即 $A = O$。反之显然。

3. **齐次性**：$\|\alpha A\| = \max_{\|x\|=1} \|\alpha Ax\| = |\alpha| \max_{\|x\|=1} \|Ax\| = |\alpha| \|A\|$。

4. **三角不等式**：
$$\|A + B\| = \max_{\|x\|=1} \|(A+B)x\| \leq \max_{\|x\|=1}(\|Ax\| + \|Bx\|) \leq \|A\| + \|B\|$$

**相容性**：
$$\|AB\| = \max_{\|x\|=1} \|ABx\| \leq \max_{\|x\|=1} \|A\| \|Bx\| = \|A\| \|B\|$$

**单位性**：$\|I\| = \max_{\|x\|=1} \|Ix\| = \max_{\|x\|=1} \|x\| = 1$。 $\square$

### 5.2 三种常用诱导范数

| 名称 | 公式 |
|------|------|
| **列和范数** $\|A\|_1$ | $\displaystyle\max_{1 \leq j \leq n} \sum_{i=1}^m \|a_{ij}\|$ |
| **行和范数** $\|A\|_\infty$ | $\displaystyle\max_{1 \leq i \leq m} \sum_{j=1}^n \|a_{ij}\|$ |
| **谱范数** $\|A\|_2$ | $\sigma_{\max}(A)$（最大奇异值） |

**关系**：$\|A\|_\infty = \|A^H\|_1$

### 5.3 谱范数

$$\|A\|_2 = \sigma_{\max}(A) = \sqrt{\lambda_{\max}(A^H A)}$$

**性质**：
1. **酉不变性**：$\|UAV\|_2 = \|A\|_2$，对任意酉矩阵 $U, V$
2. **对称性**：$\|A\|_2 = \|A^H\|_2$
3. **正规矩阵**：若 $A$ 正规（$AA^H = A^H A$），则 $\|A\|_2 = \rho(A)$

**证明（正规矩阵情形）**：
设 $A$ 正规，则 $A$ 可酉对角化：$A = U\Lambda U^H$。

于是 $A^H A = U\Lambda^H \Lambda U^H = U|\Lambda|^2 U^H$，其中 $|\Lambda|^2 = \mathrm{diag}(|\lambda_1|^2, \ldots, |\lambda_n|^2)$。

故 $\|A\|_2 = \sqrt{\lambda_{\max}(A^HA)} = \sqrt{\max_i |\lambda_i|^2} = \max_i |\lambda_i| = \rho(A)$。 $\square$

**证明（酉不变性）**：
设 $A$ 的 SVD 为 $A = U_1 \Sigma V_1^H$。

对于酉矩阵 $U, V$，有 $UAV = (UU_1) \Sigma (V_1^H V)$。

由于 $UU_1$ 和 $V_1^H V$ 仍是酉矩阵，$(UAV)^H(UAV) = V^H A^H U^H U A V = V^H(A^HA)V$。

由相似变换不改变特征值，$(UAV)^H(UAV)$ 与 $A^HA$ 有相同的特征值。

因此 $\|UAV\|_2 = \|A\|_2$。 $\square$

## 6. 谱半径定理

### 6.1 谱半径

矩阵 $A$ 的**谱半径**定义为：
$$\rho(A) = \max\{|\lambda| : \lambda \text{ 是 } A \text{ 的特征值}\}$$

### 6.2 谱半径定理

> **定理**：设 $\|\cdot\|$ 是 $\mathbb{C}^{n \times n}$ 上的相容范数，则
> $$\rho(A) \leq \|A\|$$
> 即相容范数总是**谱占优**的。

**证明**：

设 $\lambda$ 是 $A$ 的任意特征值，$x$ 为对应的特征向量。则
$$|\lambda| \|x\| = \|\lambda x\| = \|Ax\| \leq \|A\| \|x\|$$

因此 $|\lambda| \leq \|A\|$。对 $A$ 的所有特征值取最大值，得 $\rho(A) \leq \|A\|$。 $\square$

### 6.3 Gelfand 谱半径公式

> **定理**（Gelfand 公式）：设 $\|\cdot\|$ 是 $\mathbb{C}^{n \times n}$ 上的相容范数，则
> $$\rho(A) = \lim_{k \to \infty} \|A^k\|^{1/k}$$

**证明**：

**上界**：设 $\lambda$ 是 $A$ 的特征值，$x$ 是对应的特征向量。则
$$|\lambda|^k \|x\| = \|A^k x\| \leq \|A^k\| \|x\|$$

故 $|\lambda|^k \leq \|A^k\|$，即 $|\lambda| \leq \|A^k\|^{1/k}$。

对所有特征值取最大值，得 $\rho(A) \leq \|A^k\|^{1/k}$，进而
$$\rho(A) \leq \liminf_{k \to \infty} \|A^k\|^{1/k}$$

**下界**：设 $A$ 的 Jordan 标准型为 $A = P J P^{-1}$。

对于任意 $\epsilon > 0$，定义 $D_\epsilon = \mathrm{diag}(1, \epsilon, \epsilon^2, \ldots, \epsilon^{n-1})$，则
$$D_\epsilon^{-1} J D_\epsilon = \begin{pmatrix} \lambda_1 & \epsilon & 0 & \cdots \\ 0 & \lambda_2 & \epsilon & \cdots \\ \vdots & \vdots & \ddots & \ddots \end{pmatrix}$$

记 $A_\epsilon = P D_\epsilon^{-1} J D_\epsilon P^{-1}$，则 $\|A_\epsilon\| \leq \rho(A) + C\epsilon$（$C$ 为某常数）。

由于 $A_\epsilon^k \to A^k$ 当 $\epsilon \to 0$，可证
$$\limsup_{k \to \infty} \|A^k\|^{1/k} \leq \rho(A)$$

综合两式，$\lim_{k \to \infty} \|A^k\|^{1/k} = \rho(A)$。 $\square$

**推论**：$\rho(A) = \inf_{\|\cdot\|} \|A\|$，其中下确界取遍所有相容范数。

## 7. Neumann 级数

### 7.1 收敛矩阵

矩阵 $A$ 称为**收敛的**（convergent），如果 $\lim_{k \to \infty} A^k = O$。

> **定理**：$A$ 收敛 $\Leftrightarrow$ $\rho(A) < 1$。

**证明**：

**充分性**：设 $\rho(A) < 1$。由 Gelfand 谱半径公式，
$$\lim_{k \to \infty} \|A^k\|^{1/k} = \rho(A) < 1$$

故存在 $N$ 使得当 $k \geq N$ 时 $\|A^k\|^{1/k} \leq r < 1$，即 $\|A^k\| \leq r^k$。

当 $k \to \infty$ 时，$r^k \to 0$，故 $\|A^k\| \to 0$，即 $A^k \to O$。

**必要性**：设 $A^k \to O$。若 $\rho(A) \geq 1$，则存在特征值 $\lambda$ 满足 $|\lambda| \geq 1$。

设 $x$ 是对应的特征向量，则 $A^k x = \lambda^k x$。

由于 $|\lambda| \geq 1$，$\|\lambda^k x\| = |\lambda|^k \|x\| \geq \|x\|$，与 $A^k \to O$ 矛盾。 $\square$

### 7.2 Neumann 级数

> **定理**（Neumann 级数）：设 $A \in \mathbb{C}^{n \times n}$。若存在相容范数使得 $\|A\| < 1$（等价于 $\rho(A) < 1$），则 $I - A$ 非奇异，且
> $$(I - A)^{-1} = \sum_{k=0}^{\infty} A^k = I + A + A^2 + \cdots$$

**证明**：

设 $\|A\| < 1$，则级数 $\sum_{k=0}^{\infty} A^k$ 收敛（范数级数 $\sum \|A^k\| \leq \sum \|A\|^k$ 收敛）。

记 $S_N = \sum_{k=0}^{N} A^k$，则
$$(I - A)S_N = S_N(I - A) = I - A^{N+1}$$

当 $N \to \infty$ 时，$A^{N+1} \to O$（由 $\rho(A) \leq \|A\| < 1$ 及收敛矩阵定理），因此
$$(I - A) \sum_{k=0}^{\infty} A^k = I$$

即 $(I - A)^{-1} = \sum_{k=0}^{\infty} A^k$。 $\square$

### 7.3 误差估计

若 $\|A\| < 1$，则：
$$\|(I - A)^{-1}\| \leq \frac{1}{1 - \|A\|}$$
$$\left\|(I - A)^{-1} - \sum_{k=0}^{N} A^k\right\| \leq \frac{\|A\|^{N+1}}{1 - \|A\|}$$

### 7.4 Levy-Desplanques 定理（严格对角占优）

> **定理**：若 $A$ **严格对角占优**，即
> $$|a_{ii}| > \sum_{j \neq i} |a_{ij}|,\ \forall i$$
> 则 $A$ 非奇异。

**证明**：

设 $A$ 严格对角占优且奇异，则存在非零向量 $x$ 使得 $Ax = 0$。

设 $|x_k| = \max_i |x_i|$，由 $Ax = 0$ 的第 $k$ 个方程：
$$|a_{kk}||x_k| = \left|\sum_{j \neq k} a_{kj}x_j\right| \leq \sum_{j \neq k} |a_{kj}||x_j| \leq |x_k| \sum_{j \neq k} |a_{kj}|$$

这与严格对角占优条件矛盾。 $\square$

## 8. 条件数

### 8.1 定义

矩阵 $A$ 关于范数 $\|\cdot\|$ 的**条件数**定义为：
$$\kappa(A) = \|A\| \cdot \|A^{-1}\|$$

**性质**：
- $\kappa(A) \geq 1$（对于任何相容范数）
- $\kappa(A) = \kappa(A^{-1})$
- $\kappa(\alpha A) = \kappa(A)$

### 8.2 谱条件数

$$\kappa_2(A) = \|A\|_2 \|A^{-1}\|_2 = \frac{\sigma_{\max}(A)}{\sigma_{\min}(A)}$$

对于正规矩阵：$\kappa_2(A) = \frac{|\lambda|_{\max}}{|\lambda|_{\min}}$

### 8.3 条件数的几何意义

条件数刻画了线性方程组 $Ax = b$ 的解对数据扰动的敏感程度：
- $\kappa(A)$ 接近 $1$：**良态**（well-conditioned）
- $\kappa(A)$ 很大：**病态**（ill-conditioned）

**相对误差上界**：
$$\frac{\|\delta x\|}{\|x\|} \leq \kappa(A) \left(\frac{\|\delta A\|}{\|A\|} + \frac{\|\delta b\|}{\|b\|}\right)$$
